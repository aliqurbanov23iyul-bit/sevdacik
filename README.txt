SEVDANIN BALACA DÜNYASI

HTML + CSS + Vanilla JavaScript. Backend və quraşdırma tələb olunmur.
index.html faylını brauzerdə açın. Vercel-ə qovluğu statik layihə kimi yerləşdirə bilərsiniz (Framework: Other; build əmri boş; output qovluğu layihənin kökü).

İçindəkilər:
- Sevda üçün hazırlanmış mobil menyu və hərəkətli Hello Kitty səhnəsi
- 20 saniyəlik tutma oyunu və cihazda saxlanan rekord
- 6 cüt kartdan ibarət yaddaş oyunu
- 3 açılan məktub
- Təsadüfi gün sürprizi və açılan hədiyyə
- Səs düyməsi ilə açılan sakit, sintez edilmiş melodiya
- Hərəkətin azaldılması sistem seçiminə uyğun animasiyalar

Məktubları və sürprizləri dəyişmək: script.js içində letters və fortunes.
Əsas mətnlər: index.html. Rənglər: style.css içində :root.
Şəkillər əvvəlki layihədən saxlanılıb. Instagram və TikTok bölməsi ilkin saytdakı ok4nnerr istifadəçi adı ilə əlavə edilib. Dəyişmək üçün index.html faylında ok4nnerr sözünü öz istifadəçi adınızla əvəz edin.
Google Fonts internetlə yüklənir; internet olmayanda Georgia və Arial işləyir. Qalan funksiyalar və şəkillər lokal işləyir.
Heç bir cavab serverə göndərilmir. Admin panel yoxdur.

Dizayn göndərilmiş nümunələrə uyğun yenilənib: yumru qalın yazılar, konturlu çəhrayı düymələr, iri Kitty və hərəkətli sosial bölmə.
